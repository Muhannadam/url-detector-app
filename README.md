# 🛡️ Malicious URL Detector

This Streamlit app detects whether a given URL is malicious or safe using a trained Random Forest classifier.

## 🔍 Features Used
- Length, special characters, digits, presence of IPs, keywords (e.g. login, verify, account…)

## 🚀 Try it on Streamlit Cloud
Paste any suspicious link and see instant classification.

## 📦 Local Installation

```bash
git clone https://github.com/YOUR_USERNAME/malicious-url-detector
cd malicious-url-detector
pip install -r requirements.txt
streamlit run app.py
